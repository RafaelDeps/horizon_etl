## Rules for every task (read first)

These rules apply to every implementer task (T001-T068). Each task is meant to be done by someone who reads only this section and that task.

- **Order**: Strictly sequential. Do the lowest unchecked task number. A task lists what it needs under "Needs"; those are earlier task numbers.
- **No git writes**: Do not run `git commit`, `git push`, `git add`, `git rm`, `git checkout`, `git stash`, `git reset`, or anything that changes history or the index. No task below asks for it. Leave changes in the working tree.
- **Files you must never modify or open for write**: `data/exports/exports_canonical.zip`, `db/horizon.db` (and `-wal`, `-shm`), `cache/`, `data/raw/`, `CLAUDE.md`, `.prefect/`. Tests and manual checks use temporary copies (pytest `tmp_path`; or a folder under the session scratchpad).
- **No personal data**: Never write a real email, phone or CPF into any file, test, log, or message. Tests use synthetic values such as `person@example.test`, `+55 00 00000-0000` style fakes, and obviously fake CPFs. Reports hold counts and file names only.
- **Test command** (do not use `make test`: it starts Docker for a Prefect server): `PYTHONPATH=. .venv/bin/python -m pytest -q PATH`. `tests/conftest.py` already sets a test HMAC key.
- **Style**: Python 3.12-compatible code; `black` (24.10.0) and `isort` (5.13.2) formatting; `flake8` clean. Check only the files you changed: `.venv/bin/python -m black --check FILE`, `.venv/bin/python -m isort --check FILE`, `.venv/bin/python -m flake8 FILE`. Do not reformat other files.
- **Architecture**: Core logic in `src/core/logic/` imports no adapters (constitution I). Phases stay in Prefect flows; operational scripts live in `src/scripts/`.
- **"Fails first"**: After writing a test task, run it and confirm the new tests fail for the expected reason (missing function, old behavior). Then do the implementation task and confirm they pass, and that the rest of the file still passes.
- **Done means**: The task's "Accept" line is true. If it cannot be made true, stop and report why; do not widen the scope.
- **Names**: When a task names a symbol, it comes from reading the repository now; if the name differs, use the repository's.

Format: `- [ ] TID [Story] Description`. No task is marked parallel: the list is one sequence.
